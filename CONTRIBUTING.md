# Contributing

We welcome contributions to `pyvider.cty`! Please follow these general guidelines:

1.  Fork the Repository
2.  Create a Branch (`git checkout -b my-fix-branch main`)
3.  Install Dependencies (Details TBD)
4.  Make Changes
5.  Add Tests
6.  Ensure Tests Pass (`pytest`)
7.  Check Formatting/Linting (Details TBD)
8.  Update Documentation (If applicable)
9.  Submit a Pull Request

## Reporting Bugs
Please include steps to reproduce, expected behavior, actual behavior, Python version, and `pyvider.cty` version.

## Feature Requests
Provide a clear description and potential benefits.
