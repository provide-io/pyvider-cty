## 1. Core Architecture Issues & Rewrite Necessities

### 1.1 Type System Foundation

**Current Issues:**
- `CtyType` abstract base class is well-designed but implementation is inconsistent across subtypes
- Type implementations spread across multiple directories with inconsistent patterns
- Missing critical Terraform type system capabilities (unknowns, dynamic values)

**Rewrite Recommendations:**
- **Maintain** the foundational `CtyType` abstract base class with generic type support
- **Standardize** the interface across all type implementations
- **Implement** comprehensive unknown value handling
- **Simplify** type class naming (remove redundant `TF` prefix)

```python
# Clean abstract base implementation
class Type(ABC, Generic[T]):
    """Base class for all Cty types."""
    
    @abstractmethod
    def validate(self, value: Any) -> T:
        """Validate and coerce the value to this type."""

    @abstractmethod
    def equal(self, other: "Type") -> bool:
        """Check equality between this type and another."""

    @abstractmethod
    def usable_as(self, other: "Type") -> bool:
        """Determine if this type can be used as another."""
```

### 1.2 Value Handling System

**Current Issues:**
- No clear separation between types and values
- Value representation intermixed with attribute metadata
- Immutability not consistently enforced
- No proper handling of unknown values

**Rewrite Recommendations:**
- **Create** a dedicated `Value` class hierarchy completely separate from schema
- **Implement** proper immutability for all values
- **Support** unknown value representation with refinements
- **Ensure** value equality respects unknown state

```python
class Value:
    """Immutable wrapper for a Terraform-compatible value with type information."""
    
    def __init__(self, raw_value: Any, type_def: Type):
        self._raw_value = raw_value
        self._type = type_def
        
    @property
    def type(self) -> Type:
        """The type of this value."""
        return self._type
        
    @property
    def is_known(self) -> bool:
        """Whether this value is known."""
        return not isinstance(self._raw_value, UnknownValue)
```

**Rewrite Recommendations:**

class DynamicValueHandler:
    """Handles conversion between Python values and Terraform DynamicValue."""
    
    @staticmethod
    def encode(value: Value) -> DynamicValue:
        """Convert a Value to a DynamicValue protobuf message."""
        if value.is_known:
            serialized = json.dumps(value.raw_value)
            return DynamicValue(json=serialized.encode('utf-8'))
        else:
            # Handle unknown values specially
            return DynamicValue(unknown=True)
            
    @staticmethod
    def decode(dynamic_value: DynamicValue, expected_type: Type) -> Value:
        """Convert a DynamicValue protobuf message to a Value."""
        if dynamic_value.unknown:
            return UnknownVal(expected_type)
            
        if dynamic_value.json:
            data = json.loads(dynamic_value.json.decode('utf-8'))
            return Value(data, expected_type)
